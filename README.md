# Full Stack E-Commerce Backend – Spring Boot

## 📌 Project Overview
This project is a complete backend system for an E-Commerce application developed using Spring Boot. It provides secure REST APIs for user authentication, product management, cart handling, order processing and payment flow.

The project follows a layered architecture with Controller, Service, Repository and Security layers.

---

## ⚙️ Technologies Used
- Java
- Spring Boot
- Spring Security with JWT Authentication
- Hibernate & JPA
- MySQL
- Swagger UI for API documentation
- Maven

---

## ✨ Features
- User Registration & Login
- JWT Token Based Authentication
- Role Based Authorization (Admin / User)
- Product & Category Management
- Cart & Order Management
- Address Management
- Secure APIs with Spring Security
- Swagger UI Integration

---

## 🔐 Security Implementation
- Password encryption using BCrypt
- JWT Token generation and validation
- Filter-based authentication
- Custom UserDetailsService
- Role-based API access control
